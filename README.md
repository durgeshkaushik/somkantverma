# Advocate Somkant Verma — Official High Court Practice & Google Maps Client Portal

Ultra-fast, mobile-first, bilingual (English / हिंदी) static website for **Senior Advocate Somkant Verma** (High Court of Chhattisgarh, Bilaspur), specializing in **Service-Related Writ Petitions (`WP(S)`)** and **Civil Writ Petitions (`WP(C)`)**.

## Key Features
- **Google Maps Command Center**: Direct integration with `https://maps.app.goo.gl/opJ2ctvji3sQQBDs8`, multi-mode embedded map (Chamber / Satellite / High Court Route), Bilaspur landmark travel-time pills, live GPS distance calculator, and scannable QR code.
- **Zero-Email Direct Connect**: Built exclusively around direct Phone Calls (`+91 98263 16250`), structured WhatsApp case briefs, SMS, and 1-tap `.vcf` phone contact download.
- **Interactive Writ & Document Checklist Assistant**: Guides clients on exact documents required for Transfer Stays, Suspension/DE, Pension & Recovery Quashing, Promotions, Civil Writs, and Contempt Petitions.
- **Bilingual (English ⇄ हिंदी) & Dark/Light Judicial Themes**.

## Deploying to GitHub Pages (`github.io`)
1. Create a new repository on GitHub (e.g., `somkant-verma-advocate` or `<username>.github.io`).
2. Upload or push all files in this folder (`index.html`, `styles.css`, `app.js`, `somkant-verma.jpg`, `404.html`, `manifest.json`, `robots.txt`, `.nojekyll`).
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch** (`main` / `/root`), and click **Save**.
